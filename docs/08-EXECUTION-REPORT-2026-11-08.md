## 分领域研究记录

`python3 -m atlas_sources report` 会从锁定原文件重新生成 `data/reports/domain-comparisons.json`：

- **01 经济活动**：ISIC4 / ISIC5 的代码交集为 700，仅旧版有 66、仅新版有 130；共同代码有 183 个标签发生变化。这些是字面变化，不表示同码概念未变或异码概念不存在对应。两份结构文件均不含完整定义，必须补注释并解析官方版本对应表后，才能审阅 split / merge / partial。NAICS/NACE/GB/T 4754 保持独立源，尚未融合。
- **03 消费与支出**：COFOG 与 COPNI 有 42 个相同代码字符串，42 个标签都不同。前者分类政府职能、后者分类服务住户的非营利机构支出目的；不同分类对象保持独立，不建立自动映射。
- **05 职业与技能**：O*NET-SOC2019 CTDL 与 31.0 职业 CSV 各有 1,016 个代码，共同代码的标签和非空定义字节内容一致。仍保留不同来源/版次/格式记录，不因此把不同分类对象的内容模型合并进职业树。

这些比较没有生成 Atlas 自有目录和语义等价边。其余领域目前是来源发现/部分核查阶段，完整资料、许可或解析覆盖仍有缺口。生物领域仅考虑分类群/分类概念，未下载分布发生记录、序列或现实个体；临床、药物、身体功能、教育层次与领域仍分别研究。
