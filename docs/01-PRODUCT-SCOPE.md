# 目标、对象和边界

## 最终要得到什么

World Classification Atlas 是一个**世界分类目录的发现、汇集、整理与统一浏览系统**。

用户从领域进入，可以查看：
- 该领域现存哪些分类目录、各自以什么对象和原则分类；
- 原始分类的所有层级、代码、定义、版本、发布者及来源；
- 我们整理得到的一个或多个**自有目录**，可逐层下钻直到叶子；
- 自有节点与原始节点之间的对应、差异及依据；
- 尚未收集、难以对齐、存在争议的分类区域。

## 四种必须区别的东西

1. **领域（Domain）**：方便发现分类的导航分组；15 领域是开放候选集合，允许交叉。
2. **源分类（Source Scheme）**：官方/行业等外部标准的独立版本；原貌、原码、层级均保留。
3. **自有目录（Atlas Scheme）**：研究和融合后的分类成果；同领域可多套，跨领域亦可建立导航关系。
4. **目录节点（Concept/Node）**：有稳定 ID、名称、定义、父子层级和来源关联。

**分类对象**是决定目录能否真正合并的关键：行业、产品、消费用途、职业、学科、疾病、药物、物种、地理区域等不是同一对象。

## 不在当前范围

不接入现实商品、企业、组织、人物、个体物种、专利文献等实例数据；不研究供应商或组织与产品关系；不先编制“需求九大类”；不做自动生成无限分类或通用世界知识库。未来这些实例可作为每个节点的独立现实关联层，但**现在不实现**。

## 质量定义

- 来源真实：能定位发布机构、标准名称、版本、官方入口。
- 结构完整：各源的节点数、层级与父子关系可核验；不丢原始条目。
- 忠实可追溯：自有节点与来源节点映射可逆向追查，推断和事实分开。
- 融合有解释：不相同的分类对象不强行合并；不确定关系保留待审。
- 研究有覆盖：每领域能查看哪些源已登记、已采集、已解析、已对齐、未处理。
- 可探索：通过领域、目录、代码、名称检索并沿层级下钻到叶子。

## 关键设计判断

我们整理的是**多目录的世界分类地图**，不是一棵声称覆盖全世界的唯一分类树。用户可看到多个不同对象的自有目录及相互关联。原始目录不因融合而被更改。

推荐默认英文技术字段、保留原始语言，界面可显示中英文别名；不得强制机器翻译覆盖官方名称。
