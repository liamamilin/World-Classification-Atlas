## 独立承包表面处理

本轮按承包者的实际处理活动比较，分别核对旧 ISIC 第139段、当前 ISIC 第143段、旧 NACE 第81–82段和当前 NACE 第102段。审核范围要求按收费或合同加工委托方拥有的投入物。委托方只外包部分生产流程的归类规则保留为独立背景。 [ISIC Rev.4 手册](https://unstats.un.org/unsd/classifications/Econ/Download/In%20Text/ISIC_Rev_4_publication_English.pdf) · [ISIC Rev.5 白皮书](https://unstats.un.org/unsd/classifications/Econ/Download/ISIC_Rev5_Publication-white_cover_version.pdf) · [NACE Rev.2 手册](https://ec.europa.eu/eurostat/documents/3859598/5902521/KS-RA-07-015-EN.PDF.pdf/dd5443f5-b886-40e4-920d-9df03590ff91?t=1414781457000) · [NACE Rev.2.1 手册](https://ec.europa.eu/eurostat/documents/3859598/24236479/KS-01-26-047-EN-N.pdf)

第一项限定其他家用非矿物家具。旧 NACE 31.09 说明有表面处理条款。英国 ONS 原索引第100页与2024重排索引第5602、9778行可定位涂装活动。CPA 2008 第140页的31.09.91具体说明新家具在制造过程中提供的涂装服务。CPC 2.1 第145页的88901将家具制造服务连到旧ISIC 3100。两条产品与服务证据与活动绑定分别记录。通用材料的两项已审活动各用四版明文和承包者规则，当前 NACE 16.27 的成品木制品处理仍是边界竞争项。 [ONS 历史索引](https://www.ons.gov.uk/methodology/classificationsandstandards/ukstandardindustrialclassificationofeconomicactivities/uksic2007) · [CPA 2008 结构和说明](https://ec.europa.eu/eurostat/documents/6495078/19716404/CPA2008structureexplanatorynotesEN.pdf/f655ffea-01f4-47db-108e-4d35da5991d9?t=1722511832285) · [CPC 2.1 手册](https://unstats.un.org/unsd/classifications/unsdclassifications/cpcv21.pdf)

第555行仍把泛称表面处理列入旧31.01。当前→旧第558行与旧→当前第545行列出家用家具共同范围，均未单列涂装。CPA 31.01.99列办公和店铺家具制造的分包作业，单独作为专门范围的旁证。本轮为三个官方行附加涂装范围暂缓判断，旧31.01候选继续待审。已审家具承包涂装仍保留 ISIC Rev.5 组级，办公与店铺涂装、首次软包、已成形材料中间件和使用后修复依各自范围判断。 [Eurostat 官方对应入口](https://ec.europa.eu/eurostat/web/nace/correspondence-tables)

## 其他家用木制家具部件

ONS 原索引物理第60页与2024工作簿 Alphabetical Index 第5598、5631行将木制家具部件制造列为 UK SIC `31090`。ONS 前言物理第4页确认英国体系与 NACE Rev.2 对齐至四位类。NACE Rev.2 手册物理第333页附录将31.09列到 `3100*`。UNSD完整表第410行保留 `ISIC4part=1` 和 `NACE2part=0`，31.09只有一个 ISIC 目标。由此审定已成形且可识别为其他家用木制家具组成部分的独立制造，旧ISIC绑定明确标注为有界研究分配。 [ONS 原索引](https://www.ons.gov.uk/file?uri=%2Fmethodology%2Fclassificationsandstandards%2Fukstandardindustrialclassificationofeconomicactivities%2Fuksic2007%2Fsic2007indexes.pdf) · [UNSD 原始对应表](https://unstats.un.org/unsd/classifications/Econ/tables/ISIC/ISIC4_NACE2/ISIC4_NACE2.txt)

旧ISIC 3100本身没有独立木制部件条款。旧1629排除家具制造，CPC 38160提供主要生产行业旁证。专用店铺内置部件在旧ISIC的候选继续保留，泛木制部件、通用木坯与板材、办公和厨房专用部件都在本次新审定范围以外。英国五位索引继续作为独立来源证据。 [ISIC Rev.4 1629说明](https://unstats.un.org/unsd/classifications/Econ/Detail/EN/27/1629) · [CPC 38160](https://unstats.un.org/unsd/classifications/Econ/Detail/EN/1074/38160)

从仓库根目录运行。Poppler、Access解析依赖及缓存说明见 [ISIC经济活动复现](09-ISIC-ECONOMIC-ACTIVITIES.md) 和 [家具初次整理](13-FURNITURE-MULTISOURCE-ALIGNMENT.md)。

```sh
python3 -m pip install -r requirements-isic.txt --target data/local/deps
python3 -m atlas_sources validate
python3 -m atlas_sources collect
python3 -m atlas_sources verify
python3 -m atlas_sources reproduce-furniture
python3 -m atlas_sources reproduce-economy
python3 -m atlas_sources report
python3 -m unittest discover -s tests -q
node scripts/check_furniture_view.js
node scripts/check_economy_view.js
open data/local/economy/furniture/index.html
```
