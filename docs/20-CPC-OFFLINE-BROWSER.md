验收脚本在独立临时目录中只复制锁定的两个原件及其清单，重建页面和构建报告，2/2 份产物逐字节一致。注册表的缺页、可用、过期和缺资料状态通过验证。95 项 Python 单测以及 ISIC 和家具 Chrome 离线回归通过。
