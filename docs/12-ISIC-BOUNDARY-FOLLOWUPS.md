# 水冰、口罩和碳织物的边界跟进

本轮逐项跟进三个未决问题，新增四份真实官方原件、34条定位证据、三条官方行的活动范围审查及七个自有活动。仍没有足够依据批准无调味食用水冰和旧1399口罩的跨版候选；旧碳织物专门列项与宽泛列项也继续并存。结果保存了具体竞争解释和待审来源，而非通过整类合并消除疑点。未关联现实实体。

## 三项核查结果

### 无调味直接食用水冰

更正版CPC17400包括自然冰雪与人工冻结水，排除食品类食用冰到22270；后者由HS2105定义。手册主要行业表把17400列至旧3530、22270列至旧1050。CPC3.0说明仍保留该产品区分。

这些证据能区分水冰产品与食品冰产品，却没有明确证明所有直接食用、无调味水冰在新ISIC中必须由3530改派1050。原ISIC4的3530包含食用和非食用用途制冰，新版3530又排食用冰；“食用”在产品组与用途描述中的应用需要进一步解释。候选3530→1050保持`held_after_research`、`relation=null`。

新增“无调味直接食用水冰制造”目录提案，只有候选当前父级1050/3530和证据，没有已批准来源绑定，不计入263个已审/导航节点，也不补造官方子码。

### 防护口罩的旧版归属

CPC48160的呼吸器/防毒面具类别明确排除无机械部件且无可换滤芯的简单防护面罩；手册行业列为3250。旧ISIC3290又明确列防毒面具。两种来源的对象、范围和主要行业关系不同，不能据此证明所有口罩旧属3250或3290，也不能从CPC27190/HS6307的一般制成纺织品范围推断全部医用口罩旧属1392。旧1399亦缺少同一口罩的明确列项。

候选1399→3250继续暂缓。新建外科口罩、FFP2、FFP3三个自有活动，只登记Rev.5主表明确支持的当前范围；批准来源均只有Rev.5:3250，旧版来源为待审假设，关系为空。不能拿当前版节点反过来证明旧版映射。

另以两版均明确列入的手术铺单活动审查3250→3250，以金属安全头具审查3290→3290；两条均为范围限定的相关关系，不批准整个旧类等于当前类。

### 碳纤维织物范围重叠

旧1312明确列碳及芳纶织物；旧2399列非电气碳纤维及制品。CPC37990/HS6815.10及主要行业2399提供宽泛旁证，却没有取消1312的专门织造列项。由于产品主要行业不具排他性，不能据该表裁决“只有2399正确”。

原有非电气碳织物活动保留已审旧1312和当前2399的范围证据，并新增旧2399的独立待审竞争来源，关系为空。当前1312保留芳纶织造、排除非电气碳制品到2399；两版2790明确电气碳/石墨电极。新增芳纶织物、电气电极活动，明确材料、加工与用途的区别，电气2790→2790另做范围限定的相关审查。没有将碳织物、碳纤维本体和电极合成一个概念。

## 实现、证据与历史

`isic_boundaries.py`解析更正版CPC选取条目、手册行业表，并应用第四份审查输入。它绑定上一轮优先审查文件的SHA-256；旧文件字节改变即失败，不能静默继承。本轮原有审查输入文件未改写，待审对应和问题跟进各保存旧理由与新证据。

新增34条证据使总定位证据达到130条。`source_to_atlas`只含已审绑定；`source_to_candidates`单独反查七条待审来源关联。界面分别显示当前版已审、旧版待审来源和待审目录提案，并提供原工作表/物理页定位。

三项问题均变为`partially_addressed`，未冒称得到发布者答复。全体21项问题为14项open、4项partially_addressed、2项addressed_in_research、1项resolved_for_research；除研究澄清外的20项仍未完全解决。

## 复现、验证与失败

```sh
python3 -m pip install -r requirements-isic.txt --target data/local/deps
# 另需Poppler的pdftotext
python3 -m atlas_sources validate
python3 -m atlas_sources collect
python3 -m atlas_sources verify
python3 -m atlas_sources reproduce-economy
python3 -m atlas_sources report
python3 -m unittest discover -s tests -v
node scripts/check_economy_view.js
open data/local/economy/isic/index.html
```

首次缺失文件按锁重取；后续使用缓存并校验。离线重建只复制13个专项原件、manifest、锁和四份审查输入到干净目录，全部35个输出逐字节一致。实际环境与解析器/审查文件哈希写入`isic-economy.json`，比较清单在`isic-reproduction.json`。同一环境验证确定性，不承诺不同PDF工具版本自动通过字段布局哈希。

61项测试通过，新增测试覆盖当前版活动不能补造旧绑定、产品不能成为活动来源、手册表正确区分产品主列与旧产品对应列、缺表头/未知行业/重复行拒绝、父审查变动失效和待审历史保留。DOM模拟验证当前口罩、竞争来源反查和独立水冰提案，没有真实浏览器视觉验收声明。

失败如实保留在本报告：网页工具读取大PDF超时、部分旧详情路径不可达；本地受控采集四个文件全部成功。XLSX角色最初按含对应表登记，实测只有结构与说明列，已更正资源元数据并保留首次manifest；行业对应明确从PDF解析。初次用跨行连续词定位Readme失败，随后改为实际原行，哈希验证通过；审查文件尚未生成时economy也明确报缺失，生成完整输入后重建成功，没有吞错或修改源资料。

完整UNSD原件、说明、选段和工作簿仍在被Git忽略的本地目录；公开提交元数据、校验和、选取代码事实、自有活动与逐项审查说明。再分发权利未确认，UNSPSC/SNOMED两项权限阻止沿用。后续需要更明确的活动级官方解释或修订对应来解决无调味水冰、简单/过滤口罩旧来源和碳织物排他归属；现有研究已给出可复核竞争解释，未强行关闭。
