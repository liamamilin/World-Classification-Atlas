# 家具材料细类、旧部件与卫生洁具对应核查

2026-11-09 · NACE Rev.2 / Rev.2.1 与 ISIC Rev.4 / Rev.5

## 新家具表面处理

ISIC Rev.5 原版说明第113页和2026年工作簿 ISIC5 第299行将喷涂、涂漆、法式抛光等列在310组。工作簿第300行以木框或无框时木材占主要组成来判定木质家具，第301行给出3102的材料排除。本轮审定两项有明确材料条件的集成工序，分别是木质和全金属新制家用活动家具的表面处理。每个细类绑定同时要求310组工序明文、对应细类材料条件和本目录的集成制造范围。原泛材料活动保留组级绑定和细类候选，旧 ISIC 3100 到3101和3102的官方第187–188行保留 RC4.1 拆分。 [2024年原版说明](https://unstats.un.org/unsd/classifications/Econ/Download/In%20Text/ISIC5_Exp_Notes_11Mar2024.pdf) · [2026年更新工作簿](https://unstats.un.org/unsd/classifications/Econ/Download/ISIC5_Exp_Notes_19_Aug_2026.xlsx) · [2025年官方对应](https://unstats.un.org/unsd/classifications/Econ/tables/ISIC/ISIC_Rev4_to_ISIC_Rev5_Correspondence_Table-17Jan2025.xlsx)

两项子活动采用旧 NACE 31.09 的家用家具与表面处理条款。当前→旧对应表第555行同时把广义表面处理列入旧31.01，原冲突继续待审。NACE 16.27、25.51及 ISIC 2592 提供独立材料处理的竞争范围。Rev.5 白皮书物理第38页第143–144段分别讨论承包者和委托方，因而本次集成制造判断仅适用于所审子活动。独立承包处理、其他材料组合、泛材料父活动和初次软包细类仍有待审项。 [NACE Rev.2 手册](https://ec.europa.eu/eurostat/documents/3859598/5902521/KS-RA-07-015-EN.PDF.pdf/dd5443f5-b886-40e4-920d-9df03590ff91?t=1414781457000) · [NACE Rev.2.1 手册](https://ec.europa.eu/eurostat/documents/3859598/24236479/KS-01-26-047-EN-N.pdf) · [ISIC Rev.5 白皮书](https://unstats.un.org/unsd/classifications/Econ/Download/ISIC_Rev5_Publication-white_cover_version.pdf)

## 旧家具部件

NACE 当前→旧第555行的共同内容明确把店铺家具内置部件制造分到旧31.01。旧→当前第542行保留相同代码对，原共同内容为空。新增的木制内置部件子活动保留这两个方向的证据差别。当前 NACE 31.00 明文列内置部件制造，且将安装指向43.32。当前 ISIC 以310组的部件条款支持。泛木质部件父活动的两套旧版候选继续保留。 [NACE 官方对应入口](https://ec.europa.eu/eurostat/web/nace/correspondence-tables)

ISIC Rev.4 的3100列店铺家具整品制造。Rev.4 手册物理第101页的专用部件规则明确谈的是机械和设备。CPC 2.1 手册物理第87页第60行把产品38160指向其主要生产行业3100，旧 ISIC 2220另明列塑料家具配件。独立制造木制专用部件在旧 ISIC 的活动级分配仍待核实，CPC条目作为独立旁证保存。 [ISIC Rev.4 手册](https://unstats.un.org/unsd/classifications/Econ/Download/In%20Text/ISIC_Rev_4_publication_English.pdf) · [CPC 2.1 手册](https://unstats.un.org/unsd/classifications/unsdclassifications/cpcv21.pdf)

## 陶瓷家具、卫生洁具与建筑陶瓷

旧 ISIC 2392 明列陶瓷卫生洁具。旧2393包含陶瓷家具，并明确将卫生洁具排到2392。2024年原始 Rev.5 PDF 第71–72页先将卫生洁具纳入2393，又在同一类将它排向2392。2026年工作簿 Notes 第26行记录删除冲突排除，主表第199行的2393保留纳入。Notes 第25行的2392更新涉及人造石。原文支持的是说明冲突得到修正，具体活动转移日期及分配比例仍未知。 [2024年原版说明](https://unstats.un.org/unsd/classifications/Econ/Download/In%20Text/ISIC5_Exp_Notes_11Mar2024.pdf) · [2026年勘误](https://unstats.un.org/unsd/classifications/Econ/Download/Errata_for_the_Explanatory_Notes_of_the_ISICRev5_-_2026.pdf)

- 41项资源登记，39份固定快照。新下载的2024年说明有293页，SHA-256为 `b9ef4ac00d3b1736a5d7068e437babaa0105dd02ad70a86c11c9905878271ae8`。家具复现使用25份固定源输入，另复用已采集的旧版手册、白皮书和CPC手册。

## 复现

从仓库根目录运行。首次采集按锁定快照下载，已有快照可离线重建。Poppler、Access解析依赖及网络说明见 [ISIC经济活动复现](09-ISIC-ECONOMIC-ACTIVITIES.md) 和 [家具初次整理](13-FURNITURE-MULTISOURCE-ALIGNMENT.md)。

```sh
python3 -m pip install -r requirements-isic.txt --target data/local/deps
python3 -m atlas_sources validate
python3 -m atlas_sources collect
python3 -m atlas_sources verify
python3 -m atlas_sources reproduce-furniture
python3 -m atlas_sources reproduce-economy
python3 -m atlas_sources report
python3 -m unittest discover -s tests -q
node scripts/check_furniture_view.js
node scripts/check_economy_view.js
open data/local/economy/furniture/index.html
```

本地 `data/local/economy/furniture/material-boundary-source-evidence.json` 保存选取的原PDF页、2026年变更字段、辅助产品引用和相关发布者原行。 `evidence-dossiers.json` 将每个公开选择器还原为本地原文选段。 [审查决策](../data/research/furniture-material-boundary-review.json) · [公开研究目录](../data/atlas/economy/furniture-directory.json) · [家具复现报告](../data/reports/furniture-reproduction.json)
